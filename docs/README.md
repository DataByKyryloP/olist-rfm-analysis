# Olist RFM Customer Segmentation

## Project Overview
Customer segmentation using RFM analysis on Brazilian e-commerce dataset.

## Tools
- Excel (Power Query)
- PostgreSQL
- Power BI

## Workflow
Data → Excel cleaning → SQL analysis → Power BI dashboard

## Key Output
- Customer segmentation (Champion, Loyal, At Risk)
- Revenue analysis per segment
- Cohort behavior insights

## Dataset
Olist Brazilian E-Commerce (Kaggle)
